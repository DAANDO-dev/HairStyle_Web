# HairStyle Studio — Demo Website

A modern, mobile-first website for a hair salon & barber, built as a portfolio demo.

**Live demo:** https://daando-dev.github.io/HairStyle_Web/

**Features**
- Full-screen hero with booking call-to-action
- Service price list with tabs (Men / Women / Extras)
- About, gallery, team, reviews and opening hours (today highlighted)
- Booking form ready for Netlify Forms
- Sticky "Book now" button on phones, scroll animations, basic SEO

**Built with** plain HTML, CSS and JavaScript. No build step needed.

**Run locally:** open `index.html` in a browser, or use the Live Server extension.

> Demo content: the business, team, reviews and phone number are fictional. Photos from [Unsplash](https://unsplash.com).
